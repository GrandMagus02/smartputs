# @smartput/date

> A calendar day, with no time inside it.

`datetime` truncated to a day and given its own kind id, so
`tomorrow` is a date and `tomorrow at 3pm` is a datetime, and the two do not
silently unify.

## Setup

```sh
npm add @smartput/date
```

## Example

```ts
import { composeLocale, createEngine } from "@smartput/core";
import { english } from "@smartput/core/locale/en";
import { BUILTIN_KINDS } from "@smartput/kinds";
import BUILTIN_EN from "@smartput/kinds/locale/en";
import { datetime } from "@smartput/datetime";
import datetimeEn from "@smartput/datetime/locale/en";
import { date } from "@smartput/date";

const engine = createEngine({
  locales: [composeLocale(english, [...BUILTIN_EN, datetimeEn])],
  kinds: [...BUILTIN_KINDS, datetime, date],
  timeZone: "Europe/Kyiv",
});

engine.evaluate("today").formatted        // "2026-01-15 00:00 UTC"
engine.evaluate("next friday").formatted  // "2026-01-23 00:00 UTC"
engine.evaluate("3 days ago").formatted   // "2026-01-12 00:00 UTC"
```
