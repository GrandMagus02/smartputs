# @smartput/range

> Numeric and measured ranges: `10–20 km`.

`RANGE_KINDS` registers a range over every ratio kind, and `Range` is the class door onto one.

## Setup

```sh
npm add @smartput/range
```

## Example

```ts
import { sliceItems, parseSlice } from "@smartput/range";

JSON.stringify(parseSlice("2-4"))                          // "{\"start\":1,\"end\":3}"
sliceItems(["a", "b", "c", "d", "e"], "2-4").join(",")     // ""
sliceItems(["a", "b", "c", "d", "e"], "last 2").join(",")  // ""
```

Selection over a list — the "3, 5-7, last 2" a user types into a print
dialog. One-based by default, because that is what the user counted;
`ZeroIndexError` is what an index of 0 gets rather than a silent off-by-one.
