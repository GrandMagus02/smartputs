# @smartput/datasize

> Bytes and bits, decimal and binary prefixes.

Canonical in bits. `kB` and `KiB` are different units, not spellings of
one — see [Comparison](../boolean/README.md) for what that does to `1000 mb = 1
gb`.

Three doors, one table. The kind descriptor is for the
engine, `/validate` is free functions over JS numbers, `/class` is an
immutable value class — and all three read the same `UnitTable`, so a unit
added once is added everywhere. See [Validating without the
engine](../shared/README.md).

## Setup

```sh
npm add @smartput/datasize
```

## Example

```ts
import { parseDatasize, asDatasize, formatDatasize } from "@smartput/datasize/validate";
import { Datasize } from "@smartput/datasize/class";

parseDatasize("256 MB")                       // {"ok":true,"value":256,"unit":"mb","raw":"256"}
asDatasize("256 MB", "b")                     // {"ok":true,"value":256000000,"unit":"b","raw":"256000000"}
formatDatasize(parseDatasize("256 MB"))       // "256mb"
String(Datasize.parse("256 MB"))              // "256mb"

// …and the same table through the engine:
engine.evaluate("1 GB in MB").formatted       // "1,000 megabytes"
engine.evaluate("1 GiB in MiB").formatted     // "1,024 mebibytes"
engine.evaluate("700 MB + 300 MB").formatted  // "1,000 megabytes"
```

`parse` and `as` never throw — they answer `{ ok: true, … }` or
`{ ok: false, code, input }`. The value class throws on bad input and
`Datasize.tryParse` does not. All three read the one `UnitTable` below.

## Units

Read from the table itself, not typed out — a unit added to
the source appears here on the next `bun run docs:packages`. Ratios are decimal
strings, which is what lets the engine widen them to `Decimal` without a float
in between.

### DATASIZE_UNITS

| Unit | Ratio to `b` | Aliases |
| --- | --- | --- |
| `b` | `1` | `b` `byte` `bytes` |
| `kb` | `1000` | `kb` `kilobyte` `kilobytes` |
| `mb` | `1000000` | `mb` `megabyte` `megabytes` |
| `gb` | `1000000000` | `gb` `gigabyte` `gigabytes` |
| `tb` | `1000000000000` | `tb` `terabyte` `terabytes` |
| `kib` | `1024` | `kib` `kibibyte` `kibibytes` |
| `mib` | `1048576` | `mib` `mebibyte` `mebibytes` |
| `gib` | `1073741824` | `gib` `gibibyte` `gibibytes` |
| `tib` | `1099511627776` | `tib` `tebibyte` `tebibytes` |

## What it costs

Ceilings, not measurements. `bun run check-size` bundles each entry with
`bun build --minify` and fails if a row crosses its ceiling **or drops more
than 30 % below it** — a budget that is only an upper bound reports a vanished
graph as a triumph.
