# @smartput/city

The T1 gazetteer: 6,247 cities, 1,664 first-level divisions, and the two row
types. Data and no code, and no runtime dependency at all.

```ts
import { ADMIN1, CITIES } from "@smartput/city";
import { definePlace } from "@smartput/country";

const kind = definePlace({ cities: CITIES, admin1: ADMIN1 });
```

**It is a package of its own so the cost is paid by naming it.** Measured on a
minified gzipped browser bundle, countries are +27 KB over core and cities are
+234 KB on top — nearly nine times as much. `@smartput/country` therefore
exports a factory rather than a ready-made city kind, and the only edge it has
on this package is an `import type` from `@smartput/city/types`, which compiles
away. Tiering is only real when the dependency runs from the consumer inwards.

Every city over 100,000 people, plus all 241 seats of government whatever their
size — which is why Nuku'alofa is in at 22,000 and Paris, Texas is not.
A division is not a place: it carries a name and aliases, no id and no
coordinates, so `texas` alone never resolves. Divisions exist to be walked into
as a scope, which is what makes `houston texas` one literal rather than an
operation.

Both tables are generated by `scripts/geo/build.ts` and carry a hash of their
own body and of each GeoNames dump; a test recomputes them, so a hand edit fails
the suite.

Full documentation: [Places and distances](https://smartputs.dev/guide/places).
